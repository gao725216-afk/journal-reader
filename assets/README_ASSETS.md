# 资产文件说明 (Assets Guide)

## 📦 本目录需要的文件

### 🎬 动态背景
**文件名**: `bg_main.gif`
- **用途**: 全屏动态背景，营造耄耋注视的压迫感
- **建议尺寸**: 1920x1080 或更高
- **文件大小**: 建议 < 5MB（优化加载速度）
- **风格**: 暗黑系、迷离的猫眼注视效果
- **透明度**: 会在代码中设置为 15% 透明度

### 🫘 产品图
**文件名**: `product.png`
- **用途**: 九阳南北绿豆豆浆产品展示
- **建议格式**: PNG（透明背景）
- **建议尺寸**: 800x800 或更高
- **风格**: 清晰的产品照，最好有品牌 logo

### 😺 Boss 状态图（4张必备）

#### 1. `boss_idle.png`
- **用途**: Boss 常态/发呆/舔毛状态
- **建议**: 一只看起来慵懒、迷离的猫
- **尺寸**: 400x400 或更大
- **格式**: PNG 透明背景

#### 2. `boss_red_eye.png`
- **用途**: Boss 眼睛发红光状态（即将使用重拳）
- **建议**: 同一只猫，但眼睛发出红光，显得凶狠
- **提示**: 可以用 Photoshop 给眼睛添加红色发光效果
- **尺寸**: 400x400
- **格式**: PNG 透明背景

#### 3. `boss_hiss.png`
- **用途**: Boss 身体后仰哈气状态（反击姿态）
- **建议**: 猫咪张嘴哈气、身体后仰的姿势
- **风格**: 带有威慑性
- **尺寸**: 400x400
- **格式**: PNG 透明背景

#### 4. `boss_ko.png`
- **用途**: Boss 战败状态
- **建议**: 猫咪躺倒、昏迷、或失魂状态
- **风格**: 搞笑但不失尊严
- **尺寸**: 400x400
- **格式**: PNG 透明背景

### 🖼️ 梗图库（至少3张，可更多）

#### `gallery_1.gif`
- **用途**: 耄耋表情包 1
- **格式**: GIF（动图更佳）
- **尺寸**: 不限，建议 300-800px
- **内容**: 耄耋相关的搞笑梗图

#### `gallery_2.jpg`
- **用途**: 耄耋表情包 2
- **格式**: JPG/PNG
- **尺寸**: 不限
- **内容**: 迷因图片、表情包

#### `gallery_3.gif`
- **用途**: 耄耋表情包 3
- **格式**: GIF
- **尺寸**: 不限
- **内容**: 更多梗图

#### 添加更多梗图
你可以继续添加：
- `gallery_4.gif`
- `gallery_5.jpg`
- `gallery_6.png`
- ... 等等

然后在 `index.html` 的 `.gallery-container` 中添加对应的 HTML。

## 🎨 图片制作建议

### 工具推荐
1. **Photoshop** - 专业图像编辑
2. **GIMP** - 免费的 PS 替代品
3. **Figma** - 在线设计工具
4. **Canva** - 简单易用的在线工具
5. **Ezgif.com** - 在线 GIF 编辑器

### 找图资源
1. **Unsplash** - 高质量免费图片
2. **Pexels** - 免费视频和图片
3. **表情包网站** - 搜索"猫咪表情包"
4. **AI 生成** - Midjourney, DALL-E, Stable Diffusion

### 图片优化
- 使用 **TinyPNG** 压缩 PNG
- 使用 **Gifsicle** 或在线工具压缩 GIF
- 考虑使用 WebP 格式（更小的文件大小）

## 🚨 注意事项

1. **版权问题**
   - 确保你有权使用所有图片
   - 避免使用有明显水印的图片
   - 考虑使用 CC0 或 Public Domain 图片

2. **文件命名**
   - 必须严格按照上述文件名
   - 区分大小写（特别是 Linux 服务器）
   - 不要使用中文文件名

3. **文件大小**
   - 单个图片建议 < 1MB
   - GIF 动图建议 < 3MB
   - 背景 GIF 建议 < 5MB

4. **浏览器兼容性**
   - PNG/JPG/GIF 所有浏览器都支持
   - WebP 在 IE 不支持（可作为可选优化）

## 🎭 创意建议

### 背景 GIF 创意
- 一只巨大的猫眼在黑暗中缓慢眨动
- 猫影在迷雾中若隐若现
- 赛博朋克风格的猫脸全息投影

### Boss 图片创意
- 可以使用同一只猫的不同照片
- 用 Photoshop 添加特效（发光、扭曲）
- 考虑添加像素风滤镜保持视觉一致性

### 梗图库创意
- 收集真实用户的耄耋表情包
- 制作原创耄耋二创图
- 包含不同情绪：愤怒、无奈、嘲讽、卖萌

## 📞 遇到问题？

如果图片无法显示：
1. 检查文件名是否完全匹配
2. 检查文件是否在 `assets/` 目录中
3. 使用浏览器开发者工具（F12）查看 404 错误
4. 确认文件格式正确（不要把 jpg 重命名为 png）
